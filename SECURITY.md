# Security

Robot Command is maintained by Psycraft Corporation.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for an unpatched security problem.

Include the affected version or commit, a concise description, reproduction
steps, impact, and any proposed mitigation. Remove credentials, vehicle
connection details, telemetry, personal data, and other sensitive material
from reports unless it is necessary for the private investigation.

Maintainers will acknowledge reports through GitHub and coordinate a fix and
disclosure date with the reporter. Please allow time for validation and a
patched release before public disclosure.

The `0.1.0` release is an initial source release. Hardware, vehicle, and
deployment-specific security validation remains the responsibility of the
operator and deployment owner.
